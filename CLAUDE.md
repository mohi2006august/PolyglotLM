# CLAUDE.md: PolyglotLM

Guidance for Claude Code (and other AI assistants) working in this project.

## Project Summary

Adapt an open LLM to low-resource languages (e.g. Hindi, Tamil, Urdu, Bengali) by extending the tokenizer, continued pre-training, distilling from a stronger teacher and shipping a quantised model for phones. PolyglotLM is a reproducible recipe and toolkit. (1) Train new subword tokens for target scripts and merge them into the base tokenizer. Initialise new embeddings smartly (mean of sub-token embeddings or cross-lingual alignment). (2) Continued pre-training with LoRA plus trainable embeddings on cleaned web and book text. (3) Instruction tuning using data translated and generated by a strong teacher (distillation). (4) Overfitting control with per-language held-out sets and mixing ratios. (5) Quantise for on-device use. The project also produces multilingual sentence embeddings for search in these languages.

## Commands

| Command | What it does |
|---|---|
| `uv sync` | Install |
| `make data LANGS=hi,ta` | Build corpora |
| `make tokenizer` | Extend tokenizer |
| `make cpt RECIPE=recipes/indic-3b.yaml` | Train |
| `make eval` | Evaluate |
| `uv run poly demo run` | End-to-end CPU smoke run on synthetic data |
| `uv run pytest` | Test suite (CPU, tiny models) |

## Code Conventions

- All text is NFC-normalised at ingestion.
- Every checkpoint is evaluated on all languages, never just the one being trained.
- Keep functions small and typed; no silent `except`. Log with structured fields.
- Every new feature references its FR-ID in the PR description and ships with tests.
- Secrets only come from environment variables. Never hard-code keys or commit `.env`.

## Gotchas

- Resize both input embeddings and LM head (unless tied).
- llama.cpp conversion needs the merged tokenizer files.

## When Unsure

- Prefer the simplest design that satisfies the PRD; record bigger trade-offs in `BRAIN.md` → Decision Log.
- Run the eval / benchmark suite before claiming a quality or performance improvement.
- Ask before adding a new paid dependency, external service or data store.
