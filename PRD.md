# PolyglotLM: Product Requirements Document

> Adapt an open LLM to low-resource languages (e.g. Hindi, Tamil, Urdu, Bengali) by extending the tokenizer, continued pre-training, distilling from a stronger teacher and shipping a quantised model for phones.
>
> **Concepts:** `Tokenization`, `Fine Tuning`, `LoRA`, `Knowledge Distillation`, `Overfitting`, `Quantization`, `Embeddings`, `LLMs`

## 1. Overview

PolyglotLM is a reproducible recipe and toolkit. (1) Train new subword tokens for target scripts and merge them into the base tokenizer. Initialise new embeddings smartly (mean of sub-token embeddings or cross-lingual alignment). (2) Continued pre-training with LoRA plus trainable embeddings on cleaned web and book text. (3) Instruction tuning using data translated and generated by a strong teacher (distillation). (4) Overfitting control with per-language held-out sets and mixing ratios. (5) Quantise for on-device use. The project also produces multilingual sentence embeddings for search in these languages.

## 2. Problem Statement

Open LLMs perform far worse in low-resource languages. Their tokenizers split Indic or other scripts into 3–5x more tokens (higher cost, shorter effective context, slower generation), training data is scarce, and fine-tunes on small corpora overfit quickly. Speakers of these languages end up with worse, costlier AI.

## 3. Target Users & Personas

| Persona | Needs |
|---|---|
| Regional AI startup | Affordable, fluent assistant in local languages. |
| Researcher | Reproducible low-resource adaptation recipe. |
| Government/NGO | Citizen services chatbot in native languages on low-end phones. |

## 4. Goals

- Reduce token fertility for target languages by ≥ 50%.
- +20 pts on target-language benchmarks vs base model.
- ≤ 3% regression on English benchmarks.
- Run 3B quantised model at ≥ 8 tok/s on a mid-range Android phone.

## 5. Non-Goals

- Training a foundation model from scratch.
- Speech (ASR/TTS) in v1.

## 6. User Stories

- As a startup, I get a model that answers fluent Tamil questions at half the tokens of the base model.
- As a researcher, I rerun the recipe for Odia with a config change.
- As an NGO, I deploy the Q4 model in an offline Android app.

## 7. Functional Requirements

| ID | Priority | Feature | Description |
|---|---|---|---|
| FR-01 | P0 | Tokenizer extension | Train SentencePiece/BPE on target corpus; select top-N new tokens by frequency gain; merge without breaking existing IDs. |
| FR-02 | P0 | Embedding initialisation | New token embeddings = mean of their old sub-token embeddings (FVT) or aligned via bilingual dictionary. |
| FR-03 | P0 | Continued pre-training | LoRA on attention/MLP + full training of embeddings and LM head; language-mixing curriculum. |
| FR-04 | P0 | Data pipeline | Language ID, script normalisation, dedupe, quality/toxicity filters. |
| FR-05 | P1 | Teacher distillation for SFT | Teacher translates and generates instruction data; back-translation checks; cultural review. |
| FR-06 | P1 | Overfitting control | Per-language held-out perplexity, English replay buffer, early stopping. |
| FR-07 | P1 | Quantisation + mobile | GGUF Q4_K_M; llama.cpp Android build; tokenizer-aware benchmarks. |
| FR-08 | P2 | Multilingual embeddings | Distil a multilingual sentence embedder aligned with English for cross-lingual search. |

## 8. Non-Functional Requirements

- Reproducible end to end (data snapshots, configs, seeds).
- Model card with per-language evals and known limitations.
- Open licence compatibility checks on all data.

## 9. Success Metrics

| Metric | Target |

## 10. Release Plan

| Phase | Scope |
|---|---|
| M1 | Data pipeline + fertility analysis + tokenizer extension. |
| M2 | Embedding init + continued pre-training (LoRA + embeddings). |
| M3 | Teacher-distilled SFT + evals. |
| M4 | Quantisation + Android demo. |
| M5 | Multilingual embedder. |

## 11. Risks & Mitigations

| Risk | Mitigation |
|---|---|
| New embeddings destabilise model | Smart init, warm-up training embeddings only, low LR on LoRA initially. |
| Translated data sounds unnatural ('translationese') | Mix native corpora; teacher generation directly in target language; native-speaker review. |
| Catastrophic forgetting of English | 10–20% English replay; monitor English evals continuously. |
